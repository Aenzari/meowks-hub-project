# Meowks implementation roadmap

## Phase 0 — Foundation
- [x] React + TypeScript + Vite starter
- [x] Tailwind v4 styling and responsive demo dashboard
- [x] Supabase client scaffold and environment example
- [x] Initial multi-university schema and fictional Test University seed
- [ ] Run install, build, and lint checks in Codespaces
- [ ] Review and test RLS policies before real data

## Phase 1 — Identity and onboarding
- [ ] Email/password and OAuth authentication
- [ ] Profile editing and onboarding
- [ ] Optional university selection and verification
- [ ] Account deletion/export workflow

## Phase 2 — Organize
- [ ] Courses and explicit enrollment flow
- [ ] Tasks, assignments, exams, and due dates
- [ ] Calendar and dashboard data from Supabase

## Phase 3 — Learn
- [ ] Notes, flashcards, quizzes, study timer, sessions
- [ ] Spaced repetition and progress analytics

## Phase 4 — Connect
- [ ] Course discussions and comments
- [ ] Resource sharing with storage validation
- [ ] Study groups and reporting/moderation

## Phase 5 — Achieve
- [ ] Server-validated XP awards
- [ ] Streaks, achievements, weekly challenges
- [ ] Leaderboards with privacy controls

## Release gates
Before a university beta: RLS and authorization tests, upload validation, accessibility and mobile checks, privacy notice, retention/export/deletion, backups, and incident response.
